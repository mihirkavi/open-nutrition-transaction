# OpenNutri Architecture

```text
GS1 and food-provider identifiers
                |
        OpenNutri Data V1
                |
 consent -> OpenNutri Exchange V1 -> revocation
                |
 nutrition, dietitian, health, and research applications
                |
     user-controlled interpretation
```

OpenNutri standardizes the representation and permissioned movement layer. It
does not replace identifier systems, provider nutrition sources, application
intelligence, clinical workflows, or consumer choice.
