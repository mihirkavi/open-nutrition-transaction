# Manufacturer Guide

Attach source-attributed nutrition to established identifiers such as GTIN, UPC,
or EAN. Record label or formulation version, serving basis, validity dates,
allergens, and source method. Do not create a proprietary universal identifier.

Retailers may link the manufacturer record to purchased quantity and generate the
event. When a formulation changes, publish a new validity period. Corrections to
already-delivered events must reference the earlier event rather than rewrite history.
