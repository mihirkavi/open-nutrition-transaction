# OpenNutri Adoption Roadmap

1. Publish the V1 schema, specifications, examples, validator, and reference implementation.
2. Demonstrate an independent reference consumer such as ReceiptCal.
3. Recruit small restaurants, local retailers, and nutrition applications.
4. Support low-friction JSON, CSV, link, QR, API, and webhook export patterns.
5. Engage POS, ordering, and nutrition software providers as distribution partners.
6. Work with larger retailers, restaurant chains, dietitian tools, and health platforms.
7. Formalize independent multi-stakeholder standards governance.

The network becomes more useful as more providers emit OpenNutri events and more
applications consume them. Open interoperability—not ownership of the network—is the goal.
