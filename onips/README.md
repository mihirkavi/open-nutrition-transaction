# OpenNutri Improvement Proposals

An ONIP is the public design record for a normative OpenNutri change. Copy the
template, choose the next available four-digit number, explain user and ecosystem
impact, document privacy/security and compatibility, provide examples, and add tests.

States are Draft, Review, Accepted, Rejected, Withdrawn, and Final. Acceptance
does not publish a release by itself; maintainers merge the implementation and
record the released OpenNutri version separately.
