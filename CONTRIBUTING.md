# Contributing to OpenNutri

Issues and focused pull requests are welcome. Please explain the interoperability
problem, include a valid example, update the JSON Schema and TypeScript types
together, and add tests. Normative changes require an OpenNutri Improvement
Proposal (ONIP). Changes must preserve provenance, uncertainty, neutrality, user
authorization, data minimization, and the
distinction between purchased and consumed food.

By contributing, you agree that your contribution is licensed under Apache-2.0.
