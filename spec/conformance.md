# OpenNutri Conformance V1

Conformance is claimed per product and version, never for an organization as a whole.

## OpenNutri Core

Produces or consumes schema-valid events, preserves event IDs and correction
lineage, distinguishes purchase from consumption, and handles partial nutrition
without fabrication.

## OpenNutri Complete

Meets Core and implements authorization scopes, revocation, idempotent REST or
webhook delivery, historical validity, data minimization, and interoperability tests.

## OpenNutri Verified

Meets Complete and verifies the signature profile, key rotation, replay
protection, and source attribution. A verified transport signature does not prove
that every nutrition number is scientifically correct; provenance remains visible.

Claims include the conformance level, OpenNutri version, supported event types,
transport profiles, and a dated test report.
